
# Sistema Integral de Gestión de Clientes, Servicios y Reservas

## Empresa Software FJ

### Descripción del proyecto

Este proyecto consiste en desarrollar un sistema de gestión que permite administrar clientes, servicios y reservas de la empresa Software FJ.

El sistema ofrece tres tipos de servicios:

- Reserva de salas.
- Alquiler de equipos.
- Asesorías especializadas.

### Características principales

- Programación orientada a objetos.
- Clases abstractas y herencia.
- Encapsulamiento y polimorfismo.
- Validación de datos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores mediante archivos de log.
- Simulaciones de operaciones válidas e inválidas.

### Tecnologías utilizadas

- Python.
- Visual Studio Code.
- Git y GitHub.

### Ejecución del programa

Para ejecutar el sistema, utiliza el siguiente comando en la terminal:

```bash
python Main.py
```
